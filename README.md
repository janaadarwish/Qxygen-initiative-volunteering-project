# Oxygen Initiative 🍃

A single-page front-end website created as part of my **volunteering work with Oxygen Initiative**, an Egypt-based environmental volunteering community.

The website introduces the initiative, presents its environmental mission and activities, and provides visitors with easy access to its social media and community channels.

## 🌱 About the Project

As a volunteer with Oxygen Initiative, I created this landing page to help the initiative build a simple and accessible online presence.

The website gives visitors a central place to:

- Learn about Oxygen Initiative
- Understand its environmental mission
- Learn about its volunteering activities
- Connect with the initiative's community
- Access its social media platforms
- Contact the initiative directly

## ✨ Features

- Single-page responsive website
- Arabic RTL design
- Nature-inspired visual design
- Custom leaf and breath-themed logo
- Subtle breathing-rings animation
- Social media and community links
- Instagram
- X
- YouTube
- TikTok
- Facebook
- LinkedIn
